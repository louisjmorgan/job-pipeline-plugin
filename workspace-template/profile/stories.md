# Story bank

Reusable situation → action → result stories for written answers, cover letters and interviews.
Each one uses only facts confirmed in `cv.md`, `evidence.md` or reviewed answers. `facts.md`
overrides anything here.

For anonymised forms (e.g. Applied), describe employers generically ("a software company").
